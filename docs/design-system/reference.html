Colour

Swatches paint var(--name); values are read from the live theme, so they change with the theme switch.

Surfaces and lines

Text

Brand, link and focus

Lavender marks SongNodes itself: the wordmark, the one primary button, focus and selection. It never means a status. "Now" is amber.

Modules

Eight modules, one identity hue each. A tonal card is all shades of its hue; only status breaks out.

Compatibility

Energy 1–10

Low 1–4, Building 5–7, High 8–10. Always drawn with the number.

Camelot keys

Minor (A) darker, major (B) lighter. 8A = A minor, 8B = C major.
