# Decision: WP8 Graph Projection Outbox Consumer

## Context
The goal of WP8 is to implement a robust, rebuildable graph projection of track transitions, metadata, and playlist attributes from PostgreSQL into a Memgraph instance. This projection serves as the source for future harmonic, energy, and pathfinding queries.

## Decisions

1. **Memgraph Client**: The `neo4j` Python driver was selected over `pymemgraph` because it is officially supported for Memgraph (which implements the Bolt protocol), widely used, and readily available on PyPI. `pymemgraph` did not appear to be standard.
2. **Outbox Consumer Pattern**: The `graph_projection` consumer aligns perfectly with the established outbox queue system in `services/common/datalayer/outbox.py`. Handlers are designed around keyed upserts, meaning replays or duplicates naturally resolve into the correct ultimate state.

3. **Data Mapping**:
   - `silver_enriched_tracks` maps to `Track` nodes, combined with metadata edges linking to `Artist`, `Label`, `Crate`, `Source`, and `Set` when data is present in the `library` overlay.
   - `silver_track_transitions` maps to `TRANSITIONS_TO` relationships, carrying the pre-computed metadata gaps (e.g. `avg_bpm_difference`, `avg_key_compatibility`).
   - `ref_mb` (MusicBrainz reference data) is queried through `library.track_xref` to generate `REF_MB` edges (with types like `REMIX_OF`, `SAME_RELEASE`, `SAME_LABEL`) connecting `Track` nodes.
4. **Rebuild / Reconcile Mechanism**: Similar to the existing `projection_tracks` read model, `graph_projection` supports a total wipe-and-reload (`rebuild`) and statistical comparison (`reconcile`). For Memgraph, constraints/indices are first ensured, then `MATCH (n) DETACH DELETE n` is utilized to clear all data. This makes disaster recovery or schema change updates deterministic.
   - `rebuild` relies on `UNWIND $rows` batching logic, reading chunks of ~10k from PostgreSQL and batch-inserting into Memgraph to circumvent severe N+1 bottlenecks.
5. **No Independent Event Types**: Instead of adding new graph-specific outbox events, `graph_projection` intercepts existing track, artist, and library updates to ensure the graph perfectly mirrors the relational DB.

## Sources
- Memgraph Bolt API details from Neo4j client compatibility guides.
- Integration plan documentation inside `docs/integration/INTEGRATION_PLAN.md` explicitly defining P7 (Graph) functionality.

## Deviations
None. The code perfectly fulfills the requirements within the defined `WP8` bounds.
