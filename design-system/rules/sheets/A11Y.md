# A11Y rules (generated)

| ID | Rule | Check | Test |
|---|---|---|---|
| A11Y-001 | Pages shall meet WCAG 2.2 AA. | judgement | Accessibility audit finds no WCAG 2.2 AA failures. |
| A11Y-002 | Text and interactive colour pairs in the booth theme shall meet AAA contrast (7:1). | lint | Booth-theme contrast report shows every text/background pair >=7:1. |
| A11Y-003 | Hover treatment shall be a `hover-bg` wash on rows, menu items and quiet buttons, `surface-2` on secondary buttons, and `brand-strong` on primary buttons. | lint | `:hover` rules use `var(--hover-bg)`, `var(--surface-2)` or `var(--brand-strong)` per component type. |
| A11Y-004 | Links shall thicken their underline to 2px on hover. | lint | `a:hover` sets `text-decoration-thickness: 2px`. |
| A11Y-005 | Hover styles shall be applied only inside `@media (hover: hover)`, with transition `duration-fast`. | lint | Every `:hover` rule is nested in `@media (hover: hover)` and uses `var(--duration-fast)`. |
| A11Y-006 | Focus shall be shown as a 2px solid `focus` ring with a 2px offset (3px in booth) on `:focus-visible`, and shall never be removed. | lint | `:focus-visible` rule has `outline: 2px solid var(--focus)` and `outline-offset: 2px` (3px in booth). |
| A11Y-007 | Pressed state shall be a `surface-3` fill on secondary buttons and `brand-strong` on primary buttons, with `:active` and `aria-pressed="true"` for toggles. | lint | `:active` uses `var(--surface-3)` (secondary) or `var(--brand-strong)` (primary); toggles expose `aria-pressed`. |
| A11Y-008 | Selected state shall be a `brand-soft` fill with `fg` text, and chips shall invert to a `fg` fill with a check mark. | lint | Selected rows/options use `var(--brand-soft)`; selected chips use `var(--fg)` fill with a check glyph. |
| A11Y-009 | Selected items shall expose `aria-selected="true"` (rows, tabs, options), `aria-pressed` (chips) or `aria-checked` (segments). | dom | Selected rows/tabs/options have aria-selected; chips aria-pressed; segments aria-checked. |
| A11Y-010 | The current page in the drawer shall use a `brand-soft` row with a bold label, and a current link shall use a dotted underline. | lint | Drawer `[aria-current]` row uses brand-soft and font-weight bold; current link has `text-decoration-style: dotted`. |
| A11Y-011 | The now-playing or current slot shall use an amber `now` 3px inset bar, using its own token and never `brand`. | lint | Now-playing bar uses `box-shadow: inset 3px 0 var(--now)` and not `--brand`. |
| A11Y-012 | Current items shall expose `aria-current="page"`, `"step"` or `"true"`. | dom | Current nav item, step or row has the matching aria-current value. |
| A11Y-013 | Disabled controls shall use `opacity-disabled` (0.45), `fg-disabled` label, `cursor: not-allowed` and no hover change. | lint | `[disabled], [aria-disabled="true"]` use `var(--opacity-disabled)`, `var(--fg-disabled)`, `cursor: not-allowed`, and have no `:hover` override. |
| A11Y-014 | A disabled control shall show a reason nearby or in `aria-describedby`. | dom | Each disabled control has adjacent reason text or an aria-describedby target. |
| A11Y-015 | Disabled controls shall use `aria-disabled="true"` (keeps focus) or `disabled` for form fields. | dom | Non-form controls use aria-disabled; form fields use the disabled attribute. |
| A11Y-016 | A busy button shall change its label to the ongoing verb, replace its icon with `.sn-spinner`, keep its width unchanged, and ignore further clicks. | dom | Button with `aria-busy="true"` has a verb-ing label, contains `.sn-spinner`, same offsetWidth as before, and ignores click handlers. |
| A11Y-017 | A busy button or region shall set `aria-busy="true"`. | dom | Busy elements carry aria-busy="true". |
| A11Y-018 | An invalid field shall show a `status-bad` border and a cross-glyph message under the field. | dom | `[aria-invalid="true"]` has border-color `var(--status-bad)` and a message below beginning with the cross glyph. |
| A11Y-019 | An invalid field shall set `aria-invalid="true"` and `aria-describedby` pointing to the error element id. | dom | Invalid inputs have aria-invalid and aria-describedby resolving to an existing id. |
| A11Y-020 | Selected and current states shall not share the same visual treatment. | visual | Selected and current style rules differ in fill and marker. |
| A11Y-021 | State shall never be signalled by colour alone; every state shall also change a glyph, weight, outline or text. | visual | Each state differs from default by at least one non-colour property. |
| A11Y-022 | Every interactive element shall show the `focus` ring on `:focus-visible`. | lint | No interactive selector lacks a `:focus-visible` outline. |
| A11Y-023 | `outline: none` shall not be set without an equal replacement indicator. | lint | Flag `outline: none\|0` unless the same rule sets box-shadow or border replacement. |
| A11Y-024 | The focus ring shall hold 3:1 contrast on every surface. | lint | Contrast of `--focus` against each surface token is >=3:1. |
| A11Y-025 | The focus ring shall be at least 2px thick around the whole control. | lint | Focus outline-width >=2px. |
| A11Y-026 | Inside tonal cards and on module fills the focus ring shall stay `focus` (brand), not the module hue. | lint | Focus ring colour inside tonal cards equals `var(--focus)`. |
| A11Y-027 | Focus shall never be hidden under the sticky header (use `scroll-padding-top`). | dom | Tabbing through the page never leaves the focused element beneath AppHeader. |
| A11Y-028 | Focus shall never be hidden under a toast; toasts shall be bottom-aligned away from focused content. | dom | Toast container is bottom-aligned and does not overlap the focused element. |

| A11Y-031 | Everything operable by pointer shall be operable by keyboard, in a logical order, with no keyboard traps. | dom | Tab/arrow traversal reaches and operates every pointer action with no trap. |
